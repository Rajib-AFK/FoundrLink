# Project Instructions & Conventions

## Sample Domain & Email Convention

- **Mandatory Sample Domain**: All sample, demo, mock, placeholder, and seed email addresses or domain references across the entire codebase, database scripts, documentation, and tests MUST strictly use the domain **`@ripaldesign.studio`** (or **`ripaldesign.studio`**).
- **Prohibited Generic Domains**: Do not use generic or arbitrary sample domains such as `@example.com`, `@test.com`, `@startup.com`, `@foundrlink.com`, `@foundrlink.local`, etc.
- **Form Placeholders**:
  - Sign-in: `placeholder="you@ripaldesign.studio"`
  - Registration: `placeholder="alex@ripaldesign.studio"`
  - Admin/User creation: `placeholder="jane@ripaldesign.studio"`
- **Default Test Accounts**:
  - **Platform Admin:** `admin@ripaldesign.studio` | `Password123`
  - **Startup Founder:** `founder@ripaldesign.studio` | `Password123`
  - **Technical Co-Founder:** `cofounder@ripaldesign.studio` | `Password123`
  - **Angel Investor:** `investor@ripaldesign.studio` | `Password123`
